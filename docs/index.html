fixturefreeze

Frozen fixture copies · version 1.00

Purpose

Copy a file into fixtures/ with freeze, then check that the live file still matches the frozen copy.

Install

npm install -g fixturefreeze

Usage

fixturefreeze freeze path
fixturefreeze check path
