fixturefreeze

Copy a path into fixtures/ with freeze, then check that the live file still matches byte-for-byte.

1.00 / 1.0.0 branch main MIT Node.js >= 18

Overview

Golden files rot when nobody notices. fixturefreeze is a tiny freeze/check pair for generated samples, CLI output, or static HTML.

Authors of tools that emit files and want a no-framework snapshot check.

Install

Install globally from Git, or run with Node from a clone. There are no extra dependencies.

npm install -g git+https://github.com/theworker02/fixturefreeze.git
fixturefreeze --help
node src/cli.js --help

Usage

Synopsis: fixturefreeze <freeze|check> <path>

See the full CLI reference for every flag, exit code, and example.

fixturefreeze 1.00 (1.0.0)

Usage:
  fixturefreeze freeze <path>
  fixturefreeze check <path>
  fixturefreeze --help
  fixturefreeze --version

freeze  copies <path> to ./fixtures/<basename>
check   compares <path> to that frozen copy (byte-for-byte)

Options:
  -h, --help       Show this help
  -v, --version    Print 1.0.0

Examples:
  fixturefreeze freeze ./docs/index.html
  fixturefreeze check ./docs/index.html

Examples

Success

fixturefreeze freeze sample.txt
fixturefreeze check sample.txt

check prints "reason":"match" and exits 0.

Failure

After freeze, edit the live file.

echo changed >> sample.txt
fixturefreeze check sample.txt
{"ok":false,"reason":"drift"}

Exit code is 1.
