fixturefreeze

Deterministic fixture snapshots and byte-for-byte drift checks for files and directories.

1.2.0JSRMITNode.js ≥ 18

Overview

FixtureFreeze copies live content into a predictable fixtures tree and verifies it later. Version 1.2.0 adds package metadata, fixture existence checks, stronger TypeScript declarations, and richer generated symbol documentation.

Structured API

Canonical package: @theworker02/fixturefreeze

import { freeze, check, fixtureExists, PACKAGE } from "@theworker02/fixturefreeze";

freeze("./docs/index.html");
console.log(fixtureExists("./docs/index.html"));
console.log(check("./docs/index.html"), PACKAGE.version);

CLI from source

git clone https://github.com/theworker02/fixturefreeze.git
cd fixturefreeze
node src/cli.js freeze ./docs/index.html
node src/cli.js check ./docs/index.html
